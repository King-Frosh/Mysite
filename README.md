## 🚀 Key Features of This Website

- **Brand Identity**: Custom SVG logo, favicon, and brand marks for **FROSH HUB** with company logo integration for **BRICCS International Ideal Limited**.
- **Interactive Project Showcase**: Deep-dive modals and filter tabs for flagship projects including **FROSH-VAS** (telecom revenue and delivery console), **FROSH-MERGER** (SheetForge spreadsheet consolidator and compressor), and **BRICCS Corporate Platform**.
- **Interactive Resume & Print-Ready CV**: 1-click printable and PDF-exportable curriculum vitae viewable directly in-browser.
- **Dark & Light Mode**: Seamless theme toggle with local storage persistence.
- **Client Inquiries & Direct Contact**: Interactive message dispatch form with validation, copy-to-clipboard email integration, and instant feedback toasts.
- **Performance & Accessibility**: Built with Vite, React 19, TypeScript, and Tailwind CSS v4 for lightning-fast loads.

---

## 💻 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Custom Brand SVGs
- **Deployment**: Static build ready for GitHub Pages, Vercel, Netlify, or custom VPS.
